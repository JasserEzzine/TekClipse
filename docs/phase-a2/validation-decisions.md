# Validation decisions (before final test generation)

Round 1 tested the complete 21 features, seven trailing means, and seven means plus two learned relationship residual means. None met the preregistered requirement to cover E5/E7 telemetry and all three operational deviations on both validation seeds. Higher thresholds lost thermal-event coverage; reducing the feature count alone was not sufficient. The complete protocol and negative measurements are retained in `protocol-round1.json` and `selection-round1.json`.

Round 2 adds a three-dimensional contextual residual candidate. Temperature is regressed against the simulator's declared 90-minute orbital sine/cosine and time trend; voltage against battery; power against CPU and RAM. Only nominal seed 501 fits coefficients. All three residuals use trailing 60-second means. Isolation Forest remains the anomaly detector. This tests whether the broad nominal operating cycle was dominating the previous models, and whether a small set of contextual residuals exposes out-of-context readings. It narrows ML scope to these three relationships, so unexplained CPU/RAM/signal changes can remain undetected. No final test seed was inspected to introduce this candidate. The same validation objective and independent test seeds remain fixed.

The known orbit is a simulation assumption, not an estimated real spacecraft model. The linear thermal trend extrapolates poorly outside the 24-hour scientific experiment; longer dashboard previews must disclose that limitation. Benign unseen offsets remain labeled nominal and all resulting alarms count as false positives. No persistence or alert suppression is used.

Round 2's context3/q.975 detected all requested operational deviations, but emitted 170,028 false-positive seconds over the eight nominal validation runs, compared with 30,846 for all21/q.975. It is rejected for that specificity regression, despite better anomaly coverage. Higher contextual thresholds lost E5 coverage. Both the result and protocol are archived as round 2.

Round 3 tests nominal training/calibration representativeness directly: all 21 features, with alternating 90-minute blocks of additional nominal temperature/CPU noise (SD .5 C / 1 percentage point). This uses the declared Phase A benign sensor-noise regime, not attack observations. Training/calibration augmentation uses their own seeded noise; inference data is untouched. We correct the selection objective to require preservation of standard ML event coverage AND aggregate nominal false-alarm reduction. Novel operational coverage is assessed separately rather than requiring a detector that incorrectly flags harmless shifts. This is an explicit validation-stage protocol revision, not a preregistered first-attempt success. The independent test seeds and variant parameters remain unchanged and uninspected throughout selection.
