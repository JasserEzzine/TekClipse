# Actual application media

Captured on **5 October 2026** from the running `tekclipse-cloud` app using the installed Microsoft Edge browser and `scripts/check_mission_ui.py`. All displayed data is the seed-42 stored simulation; the replay clock is 1 January 2026, not the capture date.

- `e1-nominal-1920.png` / `e7-critical-1920.png`: screenshots of the actual mission-console element in a 1920×1080 browser. E7 is at +160 seconds. These are the README images.
- `*-viewport-1920.png`: full viewport captures, including normal browser-page clipping below the fold.
- `*-1366.png`: 1366×768 viewport captures. Further mission details are reachable by vertical scrolling.
- `verification.json`: measured browser timings, observed trust values, tab coverage, reset result and overflow checks. Paths inside this report refer to the original local audit capture directory.

The images are direct browser captures, with no mock data substitution, compositing or image-generation step. The original SVG artwork is generated by `tekclipse/dashboard/mission_visuals.py` from the existing state.

## Design provenance

The repository had no suitable dashboard template. The implementation extends the existing palette and Streamlit/Plotly components with original CSS and vector artwork. There is no third-party dashboard framework or spacecraft image.

Existing bundled fonts are retained with their SIL Open Font License 1.1 notices:

- [Inter license](https://github.com/JasserEzzine/TekClipse/blob/tekclipse-cloud/tekclipse/dashboard/assets/inter-OFL.txt) — Inter Project Authors, [source project](https://github.com/rsms/inter).
- [JetBrains Mono license](https://github.com/JasserEzzine/TekClipse/blob/tekclipse-cloud/tekclipse/dashboard/assets/jetbrainsmono-OFL.txt) — JetBrains Mono Project Authors, [source project](https://github.com/JetBrains/JetBrainsMono).
- [Orbitron license](https://github.com/JasserEzzine/TekClipse/blob/tekclipse-cloud/tekclipse/dashboard/assets/orbitron-OFL.txt) — Orbitron Project Authors, [source project](https://github.com/theleagueof/orbitron).

Inter provides the readable interface, JetBrains Mono the time/measurement labels, and Orbitron the retained TekClipse wordmark. Fonts remain local; the dashboard adds no remote asset/API dependency.
